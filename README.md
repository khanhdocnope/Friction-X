# Friction-X (Anti-Procrastination App)

Ứng dụng chống trì hoãn dựa trên cơ chế **Ma Sát Nhận Thức (Cognitive Friction)** và **Suy Giảm Cảm Giác (Sensory Degradation)**.

---

## 📦 Cách lấy file cài đặt APK qua GitHub Actions (Dành cho Newbie)

Bạn không cần cài đặt Flutter hay Android Studio trên máy. GitHub sẽ tự động build ra file APK cho bạn hoàn toàn miễn phí theo các bước sau:

### Bước 1: Đẩy toàn bộ thư mục này lên GitHub
1. Mở terminal hoặc ứng dụng **GitHub Desktop**.
2. Khởi tạo Git và đẩy toàn bộ code trong thư mục `d:\concentrate` lên 1 kho chứa (Repository) mới trên GitHub của bạn.

### Bước 2: Tải file APK đã build xong
1. Vào trang GitHub repository của bạn.
2. Bấm vào tab **Actions** ở phía trên.
3. Bạn sẽ thấy một tiến trình có tên **`Build Android APK`** đang tự động chạy (khoảng 3 - 5 phút).
4. Khi chạy xong (hiện dấu tích xanh ✅), bạn bấm vào tiến trình đó.
5. Cuộn xuống phần **Artifacts**, bạn sẽ thấy file **`Friction-X-Release-APK`**.
6. Bấm vào để tải file `.zip`, giải nén ra sẽ có file **`app-release.apk`** để cài trực tiếp vào điện thoại Android của bạn!

---

## ⚙️ Cài Đặt & Cấp Quyền Trên Điện Thoại Android
Khi cài file APK vào điện thoại:
1. Mở **Cài đặt (Settings)** trên Android -> **Hỗ trợ tiếp cận (Accessibility)** -> Bật **Friction-X App Tracker**.
2. Cấp quyền **Vẽ đè lên ứng dụng khác (Display over other apps)** khi ứng dụng yêu cầu.
